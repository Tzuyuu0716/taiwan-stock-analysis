# 技術指標與進出場訊號計算邏輯

## 1. 趨勢/位置指標

- **移動平均線**：5 日、20 日、60 日。判斷排列（多頭排列 = 5>20>60，空頭排列反之）與乖離率（收盤價與均線的百分比差距，乖離過大常是短線過熱/超跌的參考）
- **支撐/壓力位**：
  - 方法一：近 N 個交易日（建議 20~60 日）的高點/低點
  - 方法二：成交量密集區（volume profile）——把成交量依價格區間分桶，找出量最集中的價格帶，通常是較強的支撐/壓力
  - 興櫃股票因流動性低，方法二的可靠度會下降，建議兩種方法都算，並在輸出中註記興櫃的支撐壓力準確度較低

## 2. 動能指標

- **KD**：9 日 RSV 為基礎，K值/D值黃金交叉（K上穿D，且在低檔區）、死亡交叉（K下穿D，且在高檔區）
- **MACD**：DIF 與 MACD 訊號線交叉，搭配柱狀圖（histogram）判斷動能增減
- **RSI**：14 日，>70 視為超買區，<30 視為超賣區（僅供描述用，不做為單獨的買賣判斷依據）

## 3. 量價關係

- 股價創新高/新低時，成交量是否同步放大：
  - 價漲量增 → 動能健康
  - 價漲量縮 → 背離，動能可能減弱
  - 價跌量增 → 賣壓明顯
  - 價跌量縮 → 賣壓可能鈍化
- 興櫃股票的「量」本身就稀疏，單日爆量可能只是少數大戶議價成交，不能直接套用一般量價關係的解讀

## 4. 台股特有籌碼面

- **三大法人買賣超**：外資、投信、自營商，個別與合計買賣超金額/張數，連續買超/賣超天數是常見的觀察重點
- **融資融券**：融資餘額增加代表散戶看多（但也代表潛在賣壓），融券餘額變化反映放空力道
- 兩者若查無資料，輸出中要明確說明「無此資料」，不要用 0 或空白造成誤解
- **興櫃不適用以上兩項**（不得融資融券、不在三大法人統計範圍），改用集保戶股權分散表：
  - **大戶持股比例**：持股 400 張以上級距（集保級距 12~15）合計占集保庫存比例，逐週上升代表籌碼往大戶集中
  - **總股東人數**：逐週減少通常代表籌碼集中，增加代表分散
  - 股權分散表是週資料，變化幅度常在 0.1~0.5 個百分點，只陳述方向與幅度，不要把單週微幅變動解讀為明確訊號

## 5. 訊號整合與輸出原則

整合以上指標時，**只做客觀描述，不做操作建議**。例如：

✅ 正確寫法：
> 「近5日均線上穿20日均線，KD值於低檔黃金交叉，同時外資連續3日買超；近期支撐位約落在OO元附近（近20日低點），壓力位約在OO元（近期高點附近的量價密集區）。」

❌ 避免寫法：
> 「建議現在買進」「進場訊號確立」「這是好的買點」

## 6. 資料充分度與信心註記規則

計算任何指標前，先確認：
- 近 20 個交易日有效成交天數是否 ≥ 10 天
- 是否有連續 3 天以上零成交或極低量的狀況

若資料稀疏度不足，該檔股票（通常是興櫃）的所有技術面/籌碼面輸出都要加註「資料量不足，訊號可信度較低，僅供參考」，而不是照一般上市股的信心程度呈現。
