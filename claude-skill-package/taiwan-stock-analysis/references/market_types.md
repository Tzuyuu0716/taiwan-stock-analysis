# 上市 / 上櫃 / 興櫃 差異與判斷邏輯

## 三層級比較

| 項目 | 興櫃 | 上櫃 (TPEx) | 上市 (TWSE) |
|---|---|---|---|
| 撮合方式 | 議價制，非集中撮合 | 集中撮合 | 集中撮合 |
| 掛牌門檻 | 最低，輔導推薦券商即可登錄 | 中等 | 最嚴格 |
| 漲跌幅限制 | **無限制** | ±10% | ±10% |
| 資訊揭露完整度 | 較低 | 中等 | 最高 |
| 流動性 | 通常偏低，可能單日成交量極少 | 中等 | 較高 |
| 三大法人買賣超統計 | **不適用**（不在櫃買中心統計範圍） | 有 | 有 |
| 融資融券 | **不得**（法規排除） | 有 | 有 |
| 集保股權分散表 | 有（週資料） | 有 | 有 |

## 如何判斷代號屬於哪個層級

1. **代號查詢**：呼叫資料源時，回傳的 metadata 通常會標注市場別（例如 TWSE OpenAPI 回傳的清單只包含上市股；TPEx OpenAPI 則分別有上櫃與興櫃兩組端點）。
2. **命名慣例參考**：Yahoo 股市等平台常用後綴區分，例如 `.TW`（上市）、`.TWO`（上櫃/興櫃，兩者共用同一後綴，需另外查市場別欄位才能分辨）。
3. **興櫃日期欄位**：TPEx 興櫃專區的資料通常會有「興櫃日期」欄位，若查得到這個欄位，基本可確定是興櫃股票。
4. **若使用者只給股票名稱**：先用搜尋類工具或資料源的「代號查詢」功能取得代號與市場別，不要憑記憶假設，因為公司可能已經從興櫃轉上櫃/上市，狀態會隨時間變動。

## 興櫃特有的處理注意事項

- **無漲跌幅限制** → 不能套用「單日漲跌 ±10%」這類上市櫃常見的濾網邏輯，否則會誤判或漏判。
- **流動性稀疏** → 計算移動平均、KD、MACD 等指標前，先檢查近 20 個交易日的有效成交天數，天數過少時應該在輸出中明確降低信心註記，而不是照樣輸出一樣篤定的技術訊號。
- **不適用三大法人與融資融券制度** → 興櫃股票依「有價證券得為融資融券標準」第 2 條不具融資融券資格（[法規](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0400009&flno=2)），櫃買中心三大法人買賣超統計也只涵蓋上櫃。輸出中直接說明「興櫃不適用三大法人/融資融券制度」，不要留空白讓使用者誤以為是零。
- **籌碼面改看集保股權分散表** → 用 `get_shareholding_distribution` 取得每週各持股級距人數與比例。大戶定義為持股 400 張以上，對應集保級距 12（400,001-600,000 股）到 15（1,000,001 股以上），由工具依集保官方級距標籤判斷。觀察重點：大戶持股比例與總股東人數的逐週變化。
- **狀態會轉換**：興櫃股票可能之後轉上櫃或上市，每次查詢都應該重新確認市場別，不要沿用先前對話中記住的層級。
