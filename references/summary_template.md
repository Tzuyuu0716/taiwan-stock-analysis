# 條件式進出場摘要模板

## 核心原則

摘要的目的是把技術指標計算出來的**數字**濃縮呈現，但呈現方式一律用「條件式」語法：「如果採用某規則 → 對應數字是多少」，不能用「建議」「應該」「好買點」這類下判斷的語言。

這條規則**不能因為使用者要求更直接、更明確而放寬**。如果使用者說「不要條件式，直接告訴我該買多少」，回應方式是：仍然給出條件式數字，並說明為什麼不能給直接建議（不是投資顧問、興櫃/上市櫃風險特性不同、市場隨時變動），而不是照做。

## 摘要區塊模板

```
📊 條件式摘要（{股票代號} {股票名稱}，市場別：{上市/上櫃/興櫃}，資料截至 {日期}）

支撐參考：約 {N1} 元（近 {X} 日低點 / 成交量密集區）
壓力參考：約 {N2} 元（近 {X} 日高點 / 成交量密集區）

若採用常見規則試算（僅供參考，非建議採用）：
- 「跌破支撐 3% 停損」→ 對應參考點約 {N1 × 0.97} 元
- 「站上壓力後拉回不破前高 95% 視為型態延續」→ 對應參考點約 {N2 × 0.95} 元

籌碼面參考：{上市櫃：三大法人連續買超/賣超 X 日 / 興櫃：大戶持股比例近 N 週由 A% → B%、股東人數 C → D 人}

⚠️ 資料可信度：{一般 / 因興櫃流動性偏低，訊號可信度較低，建議搭配更長天期觀察}

以上為公開資料整理與技術指標計算結果，數字僅為特定規則下的參考試算，不構成投資建議，實際進出場決策與風險請自行評估。
```

## 停損/停利規則怎麼選（給 Claude Code 實作參考）

不要自己「選一個規則當作正確答案」，而是同時列出 2-3 種常見規則的試算結果，讓使用者自己選：

- 固定百分比停損（例如支撐價 -3%、-5%）
- 前波低點停損（跌破前一次的支撐低點）
- ATR（真實波動幅度）停損，適合波動大的股票——興櫃可考慮用這個，因為興櫃常態波動本來就大，固定百分比容易太緊

## 興櫃股票的摘要特別處理

- 支撐/壓力數字要註明「因流動性偏低，準確度較一般上市櫃股票低」
- 若近期成交天數不足（見 `indicator_logic.md` 的資料充分度規則），摘要區塊開頭就要先講「本股票資料量不足以計算穩定的支撐/壓力位，以下數字僅供參考」，而不是省略這個警語直接給數字

## 範例（僅為格式示範，非真實數據）

```
📊 條件式摘要（XXXX 範例公司，市場別：興櫃，資料截至 2026-07-08）

支撐參考：約 240 元（近20日低點）
壓力參考：約 270 元（近20日高點附近量價密集區）

若採用常見規則試算（僅供參考，非建議採用）：
- 「跌破支撐3%停損」→ 對應參考點約 233 元
- ATR停損（14日ATR約18元）→ 對應參考點約 222 元

籌碼面參考：興櫃不適用三大法人/融資融券；集保股權分散表顯示大戶（400 張以上）持股比例近 4 週由 74.1% → 74.9%，股東人數 2,880 → 2,844 人，籌碼略趨集中

⚠️ 資料可信度：因興櫃流動性偏低、近期成交天數為 12/20，訊號可信度中等，建議搭配更長天期觀察後再判斷

以上為公開資料整理與技術指標計算結果，數字僅為特定規則下的參考試算，不構成投資建議，實際進出場決策與風險請自行評估。
```
